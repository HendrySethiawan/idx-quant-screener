# Runtime dependencies, pinned exactly.

# Pinned rather than floored (`>=`) on purpose. This tool sizes real money, and a
# floor lets a rebuild months later resolve to different arithmetic without a
# single line of this repository changing -- the numbers in the ticket would move
# and nothing would say why. The floors this file used to carry (`pandas>=2.1.0`,
# `numpy>=1.24.0`) had already resolved to pandas 3.x and numpy 2.x, two major
# versions past what they were written against.
#
# Upgrading is a deliberate change: bump the pin, run the suite, run --backtest
# and compare the verdict against the previous one. If the numbers moved, the
# dependency changed the strategy and that is a finding, not a chore.
